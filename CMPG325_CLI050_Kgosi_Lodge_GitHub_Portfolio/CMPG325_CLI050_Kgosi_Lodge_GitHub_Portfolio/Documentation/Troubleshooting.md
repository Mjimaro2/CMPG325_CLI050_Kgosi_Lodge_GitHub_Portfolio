# Troubleshooting Log

Record actual problems encountered in Packet Tracer.

Suggested checks:
- `show vlan brief`
- `show interfaces trunk`
- `show ip interface brief`
- `show ip dhcp binding`
- `show ip route`
- `show access-lists`
- `show ip nat translations`

For every issue record: date, problem, observation, test/command, cause, correction and verification.
