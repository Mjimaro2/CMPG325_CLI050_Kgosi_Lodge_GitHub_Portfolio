# 15–20 Minute Video Demonstration

1. **0:00–1:30:** Introduce yourself, project ID and client.
2. **1:30–4:00:** Explain client requirements, 172.30.24.0/23, 40% growth, WPA2-PSK and Guest isolation.
3. **4:00–7:00:** Explain topology, VLANs and IP addressing.
4. **7:00–10:00:** Demonstrate VLANs, trunks, router interfaces and DHCP.
5. **10:00–12:00:** Demonstrate WPA2-PSK/AES on Staff and Guest APs.
6. **12:00–15:00:** Demonstrate Staff → server, DNS and Internet connectivity.
7. **15:00–17:30:** Demonstrate Guest → internal resources blocked and Guest → Internet allowed.
8. **17:30–19:00:** Demonstrate ACL, NAT and SSH.
9. **19:00–20:00:** Give a short reflection on design decisions, troubleshooting and learning.
